# 🌟 Shard of Light

**Shard of Light** is a 2D platformer game built with Unity.  
You play as **Arin**, a young adventurer destined to restore the shattered **Crystal of Light**.  

To succeed, you must journey across **four unique maps** filled with enemies, traps, and hidden secrets.  
The only way to complete the adventure is to collect all **four crystal shards**.

---

## 🎮 Features
- Smooth 2D platformer gameplay  
- Four distinct maps, each with unique challenges and environments  
- Multiple enemy types, traps, and hidden areas to discover  
- A fantasy storyline centered on the legendary **Crystal of Light**  

---

## 🕹️ How to Play
- Open the project in **Unity 2021.3 LTS** (or newer)  
- Press **Play** in the Unity Editor or build the project for your target platform  
- Use **Arrow keys / WASD** to move Arin, jump, and explore
